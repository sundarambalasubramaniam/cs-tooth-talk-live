# Tooth Talk — Figma ↔ Copilot ↔ GitHub SDLC Demo

> **Demo repo** for showcasing an AI-accelerated, end-to-end design-to-deployment workflow using GitHub Copilot, Figma MCP, and GitHub Actions.

## What This Demo Shows

| Step | Who | Tool |
|---|---|---|
| Designer creates/updates a Services page | Figma Designer | Figma |
| Developer generates code from the Figma design | Developer | VS Code + GitHub Copilot + Framelink MCP |
| Copilot generates Playwright tests | Developer | VS Code + GitHub Copilot |
| Code and tests pushed to GitHub | Developer | Git + GitHub CLI |
| CI automatically runs tests | Automation | GitHub Actions |
| Stakeholder feedback applied, CI re-runs | Developer | VS Code + GitHub Copilot |
| Developer's iteration pushed back into Figma | Designer | html.to.design plugin |

## Setup

### 1. Clone and install

```bash
git clone <repo-url>
cd cs-figma-mcp-demo-latest
npm install
npx playwright install --with-deps chromium
```

### 2. Configure Figma MCP

Create a `.env` file in the repo root (already gitignored):

```
FIGMA_API_KEY=<your-figma-personal-access-token>
```

Get a token: Figma → Settings → Security → Personal access tokens  
Required scopes: **File content: Read**, **Dev resources: Read**

The `.vscode/mcp.json` is already configured. Open VS Code and confirm the **Framelink Figma MCP** server shows **running** in the Copilot sidebar.

### 3. Verify tests pass locally

Start a local server first (the tests need one):

```bash
# Option A — VS Code Live Server (right-click services.html → Open with Live Server)
# Option B — terminal
npx serve . --listen 5500
```

Then in a second terminal:

```bash
npm test
# or with browser visible:
npm run test:headed
```

All 6 tests should pass.

### 4. Authenticate GitHub CLI

```bash
gh auth login
gh auth status
```

## CI/CD

GitHub Actions runs on every push and pull request. The workflow (`.github/workflows/ci.yml`) does:

1. Check out the repo
2. Install Node.js 20 + npm dependencies
3. Install Playwright + Chromium
4. Serve the static files on port 5500
5. Run `npx playwright test`
6. Upload the HTML test report as a workflow artifact

## Key Copilot Prompts (for reference)

**Generate the Services page from Figma:**
> *"Using the Figma frame at [URL], generate `services.html` with embedded CSS and vanilla JS. Reuse the CSS custom properties already defined in `aboutus.html` for brand consistency. Match the layout and design exactly."*

**Generate tests:**
> *"Generate a Playwright test file `tests/services.spec.js` that tests: the hero heading is visible, all 6 service cards render, and the bottom CTA button is present."*

**Add iterative change:**
> *"Add a prominent 'Book Appointment' button to the hero section of `services.html`. Use `var(--brand)` background with white text, same style as the existing `.btn-primary` class. Place it below the hero subtitle."*

**Update tests after change:**
> *"Update `tests/services.spec.js` to also assert that the 'Book Appointment' button is visible inside the hero section."*

## Security Notes

- `.env` is listed in `.gitignore` and will never be committed
- The Figma API key is injected at runtime via the VS Code MCP input prompt — it never touches disk when running through Copilot
- All dependencies are dev-only; there is no production server or database
